# D:\医疗 文件夹说明（小医项目 · 2026-10-24）

这里存放本项目生成的所有视频和脚本，方便保存备份。

## 视频
- `第1节~第3节-*.mp4` —— 免费入门课 3 个视频（每节约 4~5 分钟）
- `paid\` —— 8 门付费课全部 48 个课时视频（按课程分子文件夹）

## 脚本（都是跑一次即可，支持重复执行）
| 文件 | 作用 |
|---|---|
| make_lesson_videos.py | 生成免费入门课 3 个视频 |
| make_paid_videos.py | 批量生成 48 个付费课视频（断点续跑；需清掉本机代理再跑） |
| quiz_content.py | 板块测验题库（8 门课 × 5 道选择题，已并入后端 app/） |
| add_copd_courses_3.py | 给数据库补 3 门队友新建课程的内容 |
| attach_intro_videos.py（在项目 backend/scripts 里） | 给免费课配置视频地址 |
| attach_paid_videos.py | 给 48 个付费课时配置视频地址 |
| fix_lesson_durations.py | 把课时显示时长改成视频真实时长 |
